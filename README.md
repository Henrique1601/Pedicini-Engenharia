# Pedicini Construtora & Engenharia

Landing page de alta conversão para a **Pedicini Construtora** (@pediciniconstrutora).

## 🏗️ Sobre o Projeto
Landing page premium para construtora e engenharia civil focada em:
- Construções Residenciais e Comerciais de Médio e Alto Padrão
- Reformas Corporativas e Gerenciamento Completo de Obras
- Engenharia Técnica, Controle Rigoroso de Prazos e Custos (inspirado no padrão corporativo da Sienge)

## 🛠️ Tecnologias
- React / Vite / TypeScript
- Tailwind CSS & shadcn/ui
- Framer Motion / Lucide Icons
- Integração Lovable Cloud Builder
